Riemann vs Lebesgue Integration and the Normal CDF

Two ways of slicing an area (the domain or the range), what each one costs and when they disagree; then the integral that has no closed form, the standard normal CDF, and how to compute it accurately.

pt1 pt2
1. Slice the domain or the range
Riemann cuts the x-axis into intervals; Lebesgue cuts the y-axis into levels and measures where the function takes each level.
2. Compare and break them
Accuracy, convergence rate and cost on seven functions, then the Dirichlet and Thomae functions where the two approaches really differ.
3. The CDF without a closed form
Liouville's theorem, the erf function, and seven numerical methods checked against a high-precision reference, in the bulk and in the tails.

What are we doing and what is the objective?

pt1: we compute the same integrals with two definitions of "area under a curve". The Riemann one partitions the domain into subintervals and adds up (height × width). The Lebesgue one partitions the range into levels and adds up (level × measure of the set where the function takes that level). We compare accuracy, convergence and computational cost, and we test both on functions where they behave differently.

pt2: the standard normal CDF Φ(x) is an integral that cannot be written with elementary functions. We explain why (Liouville), how the special function erf gives an exact representation, and why we still need numerical methods. Then we implement several methods and measure their accuracy and speed against a trusted reference.

The objective: to understand (1) that both integrals give the same number whenever the Riemann integral exists, but the Lebesgue one covers more functions and has an error controlled by the height step; (2) that "exact" and "computable" are different things: an exact formula in terms of a special function still needs a good algorithm, and the best algorithm depends on where you evaluate it.

Study guide: start here (the vocabulary, from zero)

For pt1 (integration)

  • Integral: the (signed) area between the graph of f and the x-axis. Everything here is just different ways of computing that area approximately.
  • Partition of the domain: cutting [a, b] into N small intervals. Riemann sum: Σ f(ξi)·Δx, where ξi is a "tag" point chosen inside each interval (left end, midpoint or right end).
  • Measure μ(E): the generalized "length" of a set E ⊂ [a, b]. An interval has measure equal to its length; a finite set, or even a countable set like the rationals, has measure 0 (a null set).
  • Preimage: f−1([α, β)) = {x : α ≤ f(x) < β}, the set of inputs that produce an output in a given range. This is the key object of the Lebesgue approach.
  • Simple function: a function with finitely many values. Its integral is trivial: Σ value × measure of where it takes that value.
  • Order of convergence p: error ≈ C·n−p. On a log-log chart this is a straight line of slope −p. Larger p means that doubling the work gains more digits.

For pt2 (the normal CDF)

  • φ(x) = e−x²/2/√(2π) is the density of the standard normal; Φ(x) = ∫−∞x φ(t)dt is the probability of being below x (the CDF).
  • Elementary function: built with finitely many operations from polynomials, exp, log, trigonometric functions and their inverses. Antiderivative: a function whose derivative is the given one.
  • Special function: a named function (like erf) that is defined by an integral, series or differential equation, precisely because it is not elementary.
  • Absolute error |computed − true| versus relative error |computed − true|/|true|. For tiny probabilities (tails) only the relative error tells whether the result is meaningful.
  • Machine precision: doubles keep about 16 significant digits (about 2.2×10−16 relative). Cancellation: subtracting two nearly equal numbers destroys digits.

Riemann and Lebesgue integration

Numerical integration of a collection of functions by partitioning the domain (Riemann) and the range (Lebesgue); comparison of accuracy, convergence and efficiency; functions where they differ.

Choose a collection of interesting functions and compute their integrals numerically with approaches inspired by the Riemann definition (partitioning the domain into subintervals) and the Lebesgue definition (partitioning the range into measurable subsets and considering their preimages). Compare accuracy, convergence and computational efficiency. For Riemann-integrable functions, discuss whether the two converge to the same value. Include functions for which they behave differently (Dirichlet, Thomae).

1 The two definitions, side by side

Intuition. Imagine counting the money in a drawer. The Riemann way is to read the coins in the order they lie in the drawer and add them one by one. The Lebesgue way is to first sort the coins by value ("how many coins of 1 cent, how many of 5 cents, …") and then compute Σ value × count. Same total, different bookkeeping. In integration, the "order in the drawer" is the position x, and the "value" is f(x).

Riemann: partition the domain

Cut [a, b] into N intervals of width Δx = (b−a)/N, pick a tag ξi in each one:

RN = ∑i=1N f(ξi) · Δx (left: ξi = xi−1, midpoint, right: ξi = xi)

It works when f does not oscillate wildly inside each interval, so that one value represents the whole interval.

Lebesgue: partition the range

For f ≥ 0 with maximum value T, choose K levels of height h = T/K and yj = j·h. For each level collect the preimage:

Ej = f−1([yj, yj+1)) = {x : yj ≤ f(x) < yj+1} LK = ∑j=0K−1 yj · μ(Ej) (+ the top level)

LK is the exact integral of the simple function sK(x) = yj on Ej, which satisfies 0 ≤ f − sK < h. Therefore

0 ≤ ∫ f − LK ≤ h · (b − a)
The key difference. The Lebesgue error is bounded by the height step h times the length of the domain, whatever the shape of f: no smoothness, no continuity needed. The price: you must know the measure of the preimages μ(Ej), and that is the hard part. Equivalent form (layer cake): ∫ f = ∫0∞ μ{f ≥ t} dt.

Two ways to get μ(Ej) numerically, both implemented below. (1) Exact measures: solve f(x) = y analytically (or by bisection) to find where the function crosses each level; it needs a formula for H(t) = μ{f ≥ t}. (2) Estimated measures: evaluate f on a fine grid of M points and count how many points fall in each level (measure ≈ count·(b−a)/M); it works for any black-box f but its accuracy is limited by M.

8 Conclusion (pt1)

1. Do the two approaches converge to the same value?

Yes, for every Riemann-integrable function (and for the improper integral of 1/√x). In all the experiments the Riemann sums (left, right, midpoint) and the Lebesgue sums (exact or grid-estimated measures) tend to the same exact value (2, 1/3, 2, 1/4, 2, 1/2, Si(π)). It is a theorem, not a coincidence: the Riemann integral, when it exists, equals the Lebesgue one.

2. Accuracy and convergence

For smooth functions midpoint Riemann (order 2) is far more accurate than the Lebesgue staircase with lower levels (order 1); the mid-level variant brings Lebesgue to order 2. Left/right Riemann and the lower Lebesgue sum are all first order. For discontinuous functions both sides lose accuracy, but Lebesgue is exact on functions with few values when the preimages are known. Unbounded functions (1/√x) slow every method down to order 1/2.

3. Computational efficiency

Riemann needs B evaluations of f and nothing else. Lebesgue with exact measures needs analysis in advance (the preimages), and then is cheap or expensive depending on how hard it is to invert f. Lebesgue with estimated measures costs the same as Riemann plus binning, and is equivalent to a Riemann sum of a quantized function: it cannot beat it.

4. Where the two behave differently

On Dirichlet's function the Riemann sums have no limit (they depend on the tags) while the Lebesgue integral is 0. On Thomae's function both agree (0), but only the Lebesgue viewpoint explains it immediately (all non-zero levels are finite sets). The Lebesgue integral is the more general one; Riemann is simpler and more efficient to compute for well-behaved functions.

9 The object: Φ(x) and its relation with erf

The standard normal density and CDF are

φ(t) = e−t²/2 / √(2π) Φ(x) = ∫−∞x φ(t) dt = 1/2 + ∫0x φ(t) dt

The second equality uses the symmetry of φ and Φ(0) = 1/2. The error function is defined as

erf(z) = (2/√π) ∫0z e−t² dt erfc(z) = 1 − erf(z)
Exact relation between Φ and erf

In ∫0x φ(s) ds substitute s = √2·t (ds = √2 dt):

∫0x e−s²/2/√(2π) ds = (1/√π) ∫0x/√2 e−t² dt = (1/2) erf(x/√2)

Therefore

Φ(x) = (1/2) [ 1 + erf(x/√2) ] = (1/2) erfc(−x/√2)

Upper tail: Q(x) = 1 − Φ(x) = Φ(−x) = (1/2) erfc(x/√2). The form with erfc is the right one to use for the tails (see Section 13).

Why φ is a density: ∫ φ = 1 (polar coordinates)

Let I = ∫0∞ e−x²dx (it exists: e−x²/2 ≤ e−|x|+1, which has a finite integral, so the direct comparison test applies). Then

I² = ∫0∞∫0∞ e−(x²+y²) dx dy = ∫0π/2∫0∞ e−r² r dr dθ = (π/2)(1/2) = π/4

so I = √π/2 and, with z = √2·x, ∫−∞∞ e−z²/2dz = 2√2·I = √(2π). Hence ∫ φ = 1 and Φ(+∞) = 1. (Notice: the definite integral over the whole line has a closed form; the integral up to a finite x does not.)

Any normal distribution reduces to the standard one

If X ~ N(μ, σ²) then Z = (X − μ)/σ ~ N(0, 1), so

P(X ≤ x) = Φ((x − μ)/σ) and by symmetry Φ(−z) = 1 − Φ(z)

So a single function Φ is enough. For instance P(μ − kσ < X < μ + kσ) = Φ(k) − Φ(−k) = 2Φ(k) − 1. The table below uses our own hybrid algorithm (Section 12) to compute the famous 68-95-99.7 rule, next to the 4-digit values obtained from a printed z-table.

10 Why Φ is not an elementary function: Liouville's theorem

Since Φ′(x) = φ(x), Φ is an antiderivative of e−x²/2 (up to a constant factor). The question is whether that antiderivative can be written with elementary functions. It cannot. (Joseph Liouville proved results of this kind in the 1830s; a modern and readable account is M. Rosenlicht, "Integration in Finite Terms", American Mathematical Monthly 79 (1972), 963–972, the reference quoted in the course notes.)

Liouville's theorem, form of Ostrowski/Rosenlicht. Let f and g be rational functions, with g non-constant. Then ∫ f(x)·eg(x) dx is an elementary function if and only if there exists a rational function R such that R′(x) + g′(x)·R(x) = f(x) and in that case ∫ f eg dx = R(x)·eg(x)
Apply it to the Gaussian

Take f = 1 and g(x) = −x²/2, so g′ = −x. The condition becomes: find a rational R with R′ − x·R = 1. We show that none exists.

  • R is a polynomial of degree d ≥ 0. Then x·R has degree d + 1, while R′ has degree d − 1 at most: R′ − xR has degree d + 1 ≥ 1 and cannot equal the constant 1. (R = 0 gives 0 ≠ 1.)
  • R has a pole at some point a (complex numbers allowed) of order m ≥ 1. Then R′ has a pole of order m + 1 at a, while xR has a pole of order at most m. So R′ − xR has a pole of order m + 1 ≥ 2 at a, and cannot equal 1 (no poles).

A rational function is a polynomial plus terms with poles, so these cases cover everything: no R exists, hence ∫ e−x²/2 dx is not elementary, and neither is Φ (it differs from that integral by a constant factor and an additive constant).

What the theorem does not say. It does not say that the integrand has no antiderivative: every continuous function has one, and here it is Φ itself (the Fundamental Theorem of Calculus). The statement is that this antiderivative cannot be written in "finite terms" with elementary functions. (Textbooks sometimes say, loosely, "e−x² has no antiderivative"; the precise statement is "no elementary antiderivative".) It also does not say that the definite integral has no nice value: ∫−∞∞ e−t²/2 dt = √(2π) (Section 9), so Φ(+∞) = 1 exactly. The proof of the theorem itself belongs to differential algebra; the computation above is the part that decides this particular case.

11 Special functions: exact representation, but still numerical work

Mathematicians solve the problem by adding a new function to the vocabulary: erf is defined as the integral that is missing. With it, Φ(x) = (1/2)[1 + erf(x/√2)] is an exact analytical representation. And erf has several exact representations:

  • Integral: erf(z) = (2/√π)∫0z e−t²dt.
  • Maclaurin series (converges for every z): erf(z) = (2/√π) ∑n≥0 (−1)n z2n+1 / (n!(2n+1)).
  • Differential equation: erf″(z) + 2z·erf′(z) = 0, with erf(0) = 0 and erf′(0) = 2/√π.
  • Continued fraction for the tail (Section 12).
The series antiderivative (as in the course notes)

The power series eu = ∑ uk/k! converges for every u, so with u = −t²/2 we can integrate term by term (this is allowed inside the interval of convergence, here the whole real line):

e−t²/2 = ∑k≥0 (−1)k t2k/(2kk!) ⇒ Φ(z) = 1/2 + (1/√(2π)) ∑k≥0 (−1)k z2k+1 / (2k(2k+1)k!)

This is the same as (1/2)(1 + erf(z/√2)): substitute z/√2 in the Maclaurin series of erf and the factor √2 and the powers of 2 combine into 2k and 1/√(2π). So the "explicit antiderivative given by a series" of the lecture notes is exactly our method 3 below. It is an antiderivative in the sense of calculus, but it is not an elementary function.

A priori error bound: the Alternating Series Estimation Theorem

The series is alternating, with terms ak = z2k+1/(2k(2k+1)k!) (taking z > 0). Once the terms decrease, the error after summing the terms up to k = N is at most the first omitted term:

|Φ(z) − SN(z)| ≤ aN+1(z)/√(2π) valid as soon as N + 1 ≥ z²/2

(The terms decrease from k ≈ z²/2 on, because ak+1/ak = z²(2k+1)/(2(2k+3)(k+1)) < 1 for k ≥ z²/2.) This gives a rigorous way to pick the number of terms for any desired absolute accuracy. Section 14 draws this bound next to the error actually obtained in floating point.

Why numerics are still needed. An exact representation is not an algorithm. The integral still has to be evaluated; the series needs finitely many terms and, as we will see, can lose all its digits through cancellation (the bound above ignores rounding errors); the continued fraction converges slowly near 0. Moreover, "exact" gets us nowhere when we need a number in a program. Software libraries therefore use carefully designed approximations (for example the rational Chebyshev approximations of W. J. Cody for erf and erfc) with accuracy close to machine precision, with different formulas in different ranges of x. The task of this exercise is exactly that: build and compare such methods.

Where the series 4 comes from (and why it is "free" of cancellation)

Let g(x) = ∫0x e−s²/2 ds and y(x) = ex²/2g(x). Differentiating, y′ = xy + 1 and y(0) = 0 (the equation of Section 10!). Look for y = ∑ anx2n+1: matching coefficients gives (2n+1)an = an−1, a0 = 1, so an = 1/(1·3·5·…·(2n+1)). Then ∫0x φ = φ(x)·y(x), giving

Φ(x) = 1/2 + φ(x) · ( x + x³/3 + x⁵/(3·5) + x⁷/(3·5·7) + … )

Core code (Python; the page runs the same logic in JavaScript):

import math
SQ2PI = math.sqrt(2 * math.pi)
phi = lambda x: math.exp(-x * x / 2) / SQ2PI

def cdf_trapezoid(x, n=1000):
    h = abs(x) / n
    s = 0.5 * (phi(0) + phi(abs(x))) + sum(phi(i * h) for i in range(1, n))
    return 0.5 + math.copysign(s * h, x)

def cdf_simpson(x, n=200):                          # n even
    h = abs(x) / n
    s = phi(0) + phi(abs(x)) + sum((4 if i % 2 else 2) * phi(i * h) for i in range(1, n))
    return 0.5 + math.copysign(s * h / 3, x)

def cdf_series_alternating(x, terms=60):            # the series of the course notes (alternating)
    s, u = 0.0, 1.0                                 # u_k = x^(2k) / (2^k k!)
    for k in range(terms):
        s += (-1) ** k * u * x / (2 * k + 1)
        u *= x * x / (2 * (k + 1))
    return 0.5 + s / SQ2PI

def cdf_series(x):                                  # Marsaglia: positive terms
    s = t = x
    for i in range(1, 500):
        t *= x * x / (2 * i + 1)
        if s + t == s: break
        s += t
    return 0.5 + s * phi(x)

def tail_cf(x, depth=100):                          # Q(x) = 1 - Phi(x), for x > 0
    t = x
    for k in range(depth, 0, -1):
        t = x + k / t
    return phi(x) / t

def cdf_hybrid(x):
    if abs(x) < 2: return cdf_series(x)
    q = tail_cf(abs(x), 120 if abs(x) < 3 else 70 if abs(x) < 5 else 40)
    return q if x < 0 else 1 - q

def cdf_erf(x):                                     # library route (C erfc)
    return 0.5 * math.erfc(-x / math.sqrt(2))

# trusted reference: arbitrary precision (mpmath), 40 digits
from mpmath import mp, erfc, sqrt
mp.dps = 40
phi_ref = lambda x: erfc(-mp.mpf(x) / sqrt(2)) / 2
print(phi_ref(1.96))                                # 0.97500210485177952...

16 Conclusion (pt2)

1. Why no elementary expression

By Liouville's theorem, ∫ e−x²/2dx is elementary only if the equation R′ − xR = 1 has a rational solution; it has none (polynomials grow too fast, poles become worse). So Φ is not an elementary function, although Φ(∞) = 1 is perfectly known. The antiderivative exists (it is Φ), and it can be written as a power series, but not in elementary terms.

2. What erf gives, and what it does not

Φ(x) = (1 + erf(x/√2))/2 is an exact identity; erf also has an exact series, a differential equation and a continued fraction. But a number must still be computed, and every naive route has a weak spot: integration rules and alternating series cancel digits; erf approximations of fixed absolute accuracy are poor in the tails. The series comes with a rigorous truncation bound (Alternating Series Estimation Theorem), which does not cover rounding errors.

3. Which method to use

In practice call the library (erfc, scipy.stats.norm.cdf, math.erfc). If you must implement it: Marsaglia's series in the middle and the continued fraction in the tails (hybrid), which reaches about 10−16 relative error everywhere at the cost of a few dozen operations. For Φ(x) with x < 0 always work with the small tail directly (erfc or continued fraction), never as 1 − (1 − small).
